# Post-Mistake Distill Lab

Annotate an agent trace (must-ask / post-mistake), flip the leaderboard (isolated BFCL champ vs agent-trained 4B), and export distill JSON. Static Vite + React + TypeScript demo for Netlify. **No API keys** — sample JSONL fixtures only.

Paper framing: [JevAgentHarness](https://arxiv.org/abs/2610.21412).

## Quick start

```bash
npm install
npm run dev
```

Build for Netlify:

```bash
npm run build
```

See [DEMO.md](./DEMO.md) and [features/README.md](./features/README.md).
